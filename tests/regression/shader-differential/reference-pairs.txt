# shader-differential ours-vs-reference pairs (increment 2c).
# fields: repo-relative fragment shader path|uniform_set (default 0)|path
#   |flags (optional, column 4): extra compiler flags for OUR side, space
#   separated, on top of the path flag.  A row with flags is named
#   <shader>__<flag-slug>__set<uniform_set>, so one shader can be staged
#   under several flags or sets as distinct rows (t_3bf3ce95).
#   path = default | general | both (default both): the lowering path the
#   row is compiled on.  A row for the other path is skipped by the
#   stager, not compiled, so a fixture that only compiles under
#   --general-lowering cannot abort a default-path stage.
#
# Staged by stage-differential.ps1 only when a reference compiler is
# given; the reference containers are runtime input under dev_hdd0 and
# never enter the tree.  Byte-identical pairs are not staged.  Every
# shader listed here must compile on both sides; a refusal aborts the
# stage as a finding.  Uniform sets must exist in the stager's
# uniforms table.  sampler2D rows are allowed: the guest binds every
# referenced sampler2D BY NAME to the unit the container reports, each
# name to its own per-name image (the procedural texture with its
# channels permuted by FNV-1a(name) mod 24 - the stager prints the
# permutation per sampler), gated on the control-texture row being
# present and green; any other sampler kind, or a unit outside
# TEXUNIT0..15, refuses in-guest as samplers-unvalidated.
#
# The stager's -GeneralLowering flows into OUR side only; the reference
# side has no lowering switch.  A pair can therefore be byte-identical
# (skipped) in one mode and staged in the other -- a changed row count
# between modes is that, not a regression.
#
# First three: the Class A oracle divergences (constant-colour outputs
# where we spell the literal out and the reference reuses one constant
# slot through a swizzle, 4-5 differing bytes) -- the pixel question is
