# Required artifacts of an installed PS3DK tree.
#
# SINGLE SOURCE OF TRUTH.  Read by BOTH:
#   - cmake/ps3-self.cmake        (installed-SDK freshness probe, source-tree/Unix installs)
#   - scripts/package-windows-release.sh (Windows release payload validation)
#
# The two lists drifted before: the packager validated only flat ppu/lib stubs
# while the cmake probe additionally required lp64 variants, liblv2.a, librsx.a
# and cell/sdk_version.h -- so a release could validate clean and then fail at
# configure time.  spu-elf-to-ppu-obj.exe was absent from both, and shipped
# missing from every Windows release until v0.10.708.
#
# Format: <category> <path relative to the install root ($PS3DK / stage dir)>
# Categories:
#   host_bin   Windows host tool executable   (package validation only)
#   host_file  Windows host helper data file  (package validation only)
#   ppu_stub   PPU stub/runtime archive       (package validation)
#   sdk_core   core SDK artifact              (package validation AND cmake probe)
#   alias      stub alias + its target        (package validation AND cmake probe)
#   spu_lib    SPU runtime archive            (package validation)
#   optional   shipped but not required       (with a reason; keeps the two-sided check honest)
#
# alias rows carry THREE fields: 'alias <path> <target>', where <target> is
# relative to the alias's own directory.  sdk/Makefile and
# scripts/build-cell-stub-archives.sh install these as symlinks; the Windows
# packager materializes them into real copies (Explorer and 7-Zip do not create
# NTFS symlinks, so shipping links produced ~17-byte stubs and an unactionable
# ld error).  The assertion is therefore: exists AND (symlink resolving to
# <target> OR byte-identical to <target>).  Seeded from the real install, not
# by hand -- note libusb.a's target is libusbd_stub.a, which does not follow
# from the alias name.

# --- Shipped but not required ----------------------------------------------

# or listed here, so nothing can be added to the install without a decision.
#
