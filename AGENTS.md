# PS3 Custom Toolchain — Project Context (auto-loaded)

## What this is

A modern, open-source PlayStation 3 toolchain and SDK, **C++17-first on both PPU (PowerPC 64) and SPU (Cell SPE)**. It replaces the stale ps3dev baseline (GCC 7.2.0 / binutils 2.22 / newlib 1.20.0) with current versions, ships its own runtime, cell-style headers, NID/FNID stub archives and a Cg shader compiler, and keeps PSL1GHT homebrew building. A proprietary SDK is used privately as a coverage and behaviour measurement: it is never committed and never shipped, and none of its code is copied (the gitignored `reference/` holds the private mount and its policy).

## Status snapshot

- **Releases:** tag-driven (`docs/RELEASING.md`, `docs/VERSIONING.md`); the latest is in `CHANGELOG.md`. Each release ships the Windows SDK zip (the `.exe` cross-compilers, runtime, SDK, portlibs, CMake files and samples), Windows and Linux host-tools packages, the Linux `ps3dev-ppu` / `ps3dev-spu` toolchain tarballs and a source tarball.
- **Toolchain:** PPU GCC 16.1.0, SPU GCC 16.1.0 (SPU backend forward-ported from 9.5.0), binutils 2.42, newlib 4.4.0, PPU GDB 14.2.
- **PPU ABI:** ELF64 with 32-bit pointers by default (ILP32; Pmode DImode, ptr_mode SImode since v0.23.0); `-mlp64` selects the LP64 multilib. See `docs/abi/cellos-lv2-abi-spec.md`.
- **SDK:** native LV2 runtime (`runtime/lv2`), cell-style headers and libraries under `sdk/`, stub archives generated by `tools/nidgen`; coverage in `docs/coverage.md`.
- **Shaders:** `tools/rsx-cg-compiler` is the recommended Cg vertex/fragment compiler; PSL1GHT's `cgcomp` is still bundled for old Makefiles.
- **In progress:** the GCC 16 transition (`docs/design/gcc-transition.md`): GCC 16.1.0 is the only PPU compiler in the build and release scripts (the 12.4 path is gone); the stage-2 exit gates that are not yet measured stay pending, and objects built by a 12.4 release must be rebuilt. The SPU compiler is GCC 16.1.0 too (the backend forward-port, stage 3); objects built by an older SPU compiler must be rebuilt as well.

## Locked-in decisions

| Decision | Choice |
|---|---|
| Build host | Native Linux (CI: Ubuntu); on Windows, build inside WSL2. Native MSYS2 is not a supported bootstrap path. |
| Windows users | Windows-hosted `.exe` toolchain cross-built from Linux with `--host=x86_64-w64-mingw32`, shipped in every release zip. |
| PPU compiler | GCC 16.1.0 (`powerpc64-ps3-elf`, `patches/ppu/gcc-16.x`); it replaced GCC 12.4.0 (`docs/design/gcc-transition.md`). |
| SPU compiler | GCC 16.1.0 (`spu-elf`, `patches/spu/gcc-16.x` on the 9.5.0 backend restored from `releases/gcc-9.5.0`; `docs/design/spu-gcc16-port.md`). `--gcc=9` still builds 9.5.0. |
| binutils | 2.42 for both targets, with small PS3 patch series (`patches/ppu/binutils-2.42`, `patches/spu/binutils-2.42`). |
| newlib | 4.4.0 with the PS3 `libsysbase` / lv2 glue (`patches/ppu/newlib-4.x`, `patches/spu/newlib-4.x`). |
| GDB | 14.2, PPU only. |
| PSL1GHT | Supported front-end with Cell-style naming; pinned in `scripts/bootstrap.sh` and patched by `patches/psl1ght/series`. |
| Shader compiler | `rsx-cg-compiler` (independent Cg → NV40); output compatible with the established compiler is the target (differences, including optimisation differences, are tracked; byte identity is not the release bar); extensions only where advised. |
| Host tooling | Rust workspace in `tools/` (nidgen, coverage-report, abi-verify, prx-gen, sfo, make-sdata, ovis, spu-elf-to-ppu-obj), plus `rsx-cg-compiler` (C++) and `sprx-linker` (C). |

## Build orchestration

```bash
source ./scripts/env.sh
./scripts/bootstrap.sh                 # upstream mirrors (add --with-reference-repos for ps3dev/forks)
./scripts/build-spu-toolchain.sh
./scripts/build-ppu-toolchain.sh
./scripts/build-psl1ght.sh             # PSL1GHT runtime + our LV2 runtime, into $PS3DK
./scripts/build-sdk.sh --headers-only
./scripts/build-cell-stub-archives.sh
./scripts/build-portlibs.sh            # or name recipes: build-portlibs.sh 060-tiny3d
./scripts/build-sdk.sh                 # SDK libraries + host tools (--no-host-tools to skip them)
```

This is the release order (`.github/workflows/release.yml`). The toolchain scripts take `--only <step>` and `--clean`: PPU steps are binutils, gcc-newlib, gdb and symlinks; SPU steps are binutils, gcc-newlib, symlinks and linker-script. Every patch series applies with `--fuzz=0`.

## House rules

- Never commit to `reference/` (`.gitignore` enforces).
- Never copy proprietary SDK code into the repo. Independent only.
- Session handoff briefs and sample-sweep reports are LOCAL-ONLY: they live in the gitignored `docs/local/` and are never committed (director, 2026-08-29).
- `.gitattributes` keeps `patches/**` byte-exact (no CRLF).
- Build trees go under `$PS3_BUILD_ROOT` (default `$HOME/ps3tc/build`) to dodge MAX_PATH on Windows and keep `stage/` clean.
- Use the `--only` flag on build scripts for incremental work; full rebuild only when patches change.
